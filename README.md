# Portal de Consulta de Produtos

Portal web para buscar produtos, montar listas para consulta e solicitar cadastros com interface moderna e fluxo operacional.

## Como executar

1. Abra o arquivo `index.html` em um navegador.
2. Caso deseje publicar no GitHub Pages, use a opção de publicar a pasta raiz do repositório.

## Observações

- A interface depende de dados externos em Firebase para catálogo de produtos.
- O projeto foi estruturado para uso em ambiente interno com busca avançada e integração com e-mail do Outlook.
